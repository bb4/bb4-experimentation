# bb4-experimentation

📊 [Build status for all bb4 projects](https://github.com/bb4/.github)

Some experimental projects built using the bb4 framework. Some are just quick prototypes or tests, while others may be split out into a separate repository when mature enough.

**Build conventions:** this repo uses [bb4-gradle](https://github.com/barrybecker4/bb4-gradle) **3.0-SNAPSHOT** via `com.barrybecker4.bb4.settings` and the `bb4Libs` version catalog (Java **25**, Gradle **9.1+**, wrapper **9.8.2**). A sibling `../bb4-gradle` checkout is preferred for local plugin work; otherwise the plugin resolves from Maven Central snapshots.
